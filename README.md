**ReCode — Code. Compete. Improve.**

ReCode is a competitive coding platform inspired by Codewars, Reddit, and Wordle. Solve a new coding challenge every day, compete with friends in teams of up to 5 or challenge yourself solo, and climb the global leaderboards. Learn from hints, share solutions with the community, and code directly in your browser or favorite IDE through the ReCode plugin. Build your skills one challenge at a time.
