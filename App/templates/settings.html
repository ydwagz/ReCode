VS Code
  1. Install the extension from plugins/vscode in the ReCode repo (Extensions → … → Install from VSIX, or open the folder and press F5).
  2. Run ReCode: Set API Token and paste the token above. Set recode.serverUrl to {{ request.scheme }}://{{ request.get_host }}.
  3. Use ReCode: Pull Today's Challenge, Run Examples and Submit Current File.
Any editor (CLI)

export RECODE_TOKEN=<your token>
python plugins/recode_cli.py pull          # writes today's starter file
python plugins/recode_cli.py run  solution.py
python plugins/recode_cli.py submit solution.py
